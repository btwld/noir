# Noir documentation

Build terminal apps in Dart with widgets, retained state, and layout measured
in cells. Start with a small app, then add input and reactive state as you need them.

<PrereleaseNotice>
  Noir is a prerelease. The published package is alpha.4; the optional
  `noir_signals` companion currently requires a repository checkout. [Check
  package availability](/api) before choosing an example.
</PrereleaseNotice>
