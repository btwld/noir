# Hooks

Hooks are an opt-in way to compose local state and lifecycle behavior. Import
the normal widget surface first, then add `package:noir/hooks.dart`:

```dart
import 'package:noir/noir.dart';
import 'package:noir/hooks.dart';
```

The Hooks library ships in the main Noir package and is built only on the
supported high-level widget API.

## Start with a HookWidget

The [Hooks Counter](https://github.com/leoafarias/noir/blob/main/example/hooks_counter.dart)
keeps `useState` at the top level of `build` and changes its value from a Button
callback.

```dart
class HooksCounterApp extends HookWidget {
  const HooksCounterApp({super.key});

  @override
  Widget build(BuildContext context) {
    final count = useState<int>(0);
    return Button(label: '+ Add one', onPressed: () => count.value++);
  }
}
```

`useState` owns and observes a `ValueNotifier`. Changing `count.value` rebuilds
the `HookWidget`. This is the hook form of [Counter’s `setState`](/examples#counter),
not a replacement for Noir’s foundational state model.

## Keep hook order stable

Stateful hooks use call order as identity. Call them unconditionally and in the
same order on every build. Do not call a hook from an event handler, effect,
cleanup function, or another lifecycle callback. Top-level custom hooks should
begin with `use`.

`useContext` and `useTickerProvider` are build-only lookups, so they do not
consume hook slots. A hook key changes only that slot. Noir snapshots key lists,
which prevents later caller mutation from changing stored identity.

## Use effects for external resources

`useEffect` runs synchronously. Use it to synchronize an external resource and
return its cleanup—not to handle a button press. Without keys, cleanup runs and
the effect starts again on every build. With keys, Noir replaces the effect only
when those keys change. Cleanup also runs when the hook disappears or the widget
is disposed.

An effect or cleanup must not request a synchronous hook rebuild. Schedule a
later update from a timer, future, stream, or user event instead.

## Pick the smallest hook that owns the job

Core hooks include `useState`, `useEffect`, `useMemoized`, `useCallback`, and
`useRef`. Noir also provides `useAnimationController`,
`useTextEditingController`, `useFocusNode`, `useScrollController`, and
`useViewportController`.

Keep a future or stream outside `build`, or retain it with `useMemoized`, so a
rebuild does not restart the work.
