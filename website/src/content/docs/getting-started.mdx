# Getting started

Noir is a Flutter-like reactive terminal UI framework for Dart, powered by
OpenTUI. This guide starts with a small stateful app, then shows the same local
state with Hooks.

<PrereleaseNotice />

## Add Noir to a Dart package

Run the install command from your package directory:

<InstallCommand />

## Run your first app

Save this as `bin/noir_demo.dart`:

```dart
import 'package:noir/noir.dart';

void main() => runTuiApp(const CounterApp(), enableMouse: true);

class CounterApp extends StatefulWidget {
  const CounterApp({super.key});

  @override
  State<CounterApp> createState() => _CounterAppState();
}

class _CounterAppState extends State<CounterApp> {
  int _count = 0;

  @override
  Widget build(BuildContext context) => Column(
    crossAxisAlignment: CrossAxisAlignment.start,
    spacing: 1,
    children: [
      Text('Count: $_count'),
      Button(
        autofocus: true,
        label: '+ Add one',
        onPressed: () => setState(() => _count++),
      ),
    ],
  );
}
```

Run it:

```sh
dart run bin/noir_demo.dart
```

Press Enter or Space to update the count. With mouse reporting enabled, you
can also click the button. Press Ctrl+C to exit.

The event calls `setState`, which marks the retained state as changed. Noir
rebuilds that declaration, lays it out in terminal cells, and records the next
frame.

For the complete repository example—with Up, Down, `+`, `-`, Enter, Space, and
pointer handling—run:

```sh
dart run example/counter.dart
```

[Read the complete Counter source](https://github.com/leoafarias/noir/blob/main/example/counter.dart).

## Express the same state with Hooks

`StatefulWidget` is Noir’s foundational state model. Its state class makes
lifecycle ownership explicit. Hooks are an opt-in way to express the same
local state when composable lifecycle helpers make the component easier to
read.

```dart
import 'package:noir/noir.dart';
import 'package:noir/hooks.dart';

class HooksCounterApp extends HookWidget {
  const HooksCounterApp({super.key});

  @override
  Widget build(BuildContext context) {
    final count = useState<int>(0);
    return Button(label: '+ Add one', onPressed: () => count.value++);
  }
}
```

Hooks ship in the main Noir package but stay outside the default
`package:noir/noir.dart` namespace. Read the
[Hooks Counter source](https://github.com/leoafarias/noir/blob/main/example/hooks_counter.dart)
and the [Hooks guide](/docs/hooks) before adding effects or controller hooks.

## Work from a source checkout

The repository can be ahead of the latest published prerelease. To evaluate an
unreleased API beside a checkout, use a path dependency:

```yaml
dependencies:
  noir:
    path: ../noir
```
