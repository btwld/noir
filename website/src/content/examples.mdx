# Examples

These examples ship with Noir and use supported package APIs. The six featured
casts are authentic asciicast v2 recordings produced through Noir’s headless
driver. They prove the same layout, paint, and parsed-input paths used by the
ordinary suite; they do not claim real-terminal or raw-mode proof.

## Featured examples

>
  <ol>
    <li>
      A focused <code>Focus</code> handles Up, Down, +, -, Enter, and Space; the{' '}
      <code>PointerListener</code> routes a left click to the same increment
      method.
    </li>
    <li>
      The retained <code>_CounterAppState</code> owns <code>_count</code> and

    </li>

      terminal cells.
    </li>
    <li>
      The rebuilt declaration is laid out and painted as the next terminal
      frame.
    </li>
  </ol>
  <p>
    Compare it with{' '}
    <a href="https://github.com/leoafarias/noir/blob/main/example/hooks_counter.dart">
      Hooks Counter
    </a>
    : <code>useState</code> owns the local notifier, while the same input
    callback changes <code>count.value</code>. The{' '}
    <a href="/docs/hooks">Hooks guide</a> explains the opt-in public surface and
    its lifecycle rules.
  </p>
</ExampleSection>

  id="like-reactor"

  run="dart run example/like_reactor.dart"
  controls="Space, Enter, or a left click emits a burst; Ctrl+C exits."
  sourceHref="https://github.com/leoafarias/noir/blob/main/example/like_reactor.dart"
  testHref="https://github.com/leoafarias/noir/blob/main/test/example/like_reactor_test.dart"
  guideHref="/docs/state-lifecycle"
  demo={{
    id: 'like-reactor',
    title: 'Like Reactor — bounded motion',
    castUrl: '/demos/like-reactor.cast',
    cols: 72,
    rows: 24,
    poster:
      'NOIR · LIKE REACTOR\n\n       ♥  ✦  ♡  ♥\n\n          █████\n        █████████\n          █████\n\nSpace/Enter/click burst · Ctrl+C exit',
  }}
>
  <ol>
    <li>
      A focused key handler and the heart’s <code>PointerListener</code> both
      call one burst action.
    </li>
    <li>
      <code>AnimationController</code> ticks the simulation; each burst emits
      deterministic particles and the list is capped at 72.
    </li>
    <li>
      Particles project into a fixed 56-by-8 cell stage, clamping their
      coordinates before rows are painted; the heart has its own fixed
      footprint.
    </li>
    <li>
      The controller stops once no frame work remains, then restarts for the
      next activation; disposal clears owned simulation state and listeners.
    </li>
  </ol>
</ExampleSection>

  demo={{
    id: 'pulse',
    title: 'Pulse — controller lifecycle',
    castUrl: '/demos/pulse-animation.cast',
    cols: 56,
    rows: 18,
    poster:
      'Terminal-native motion\n\n████████████████░░░░░░░░░░░░░░░░\n\ncontroller.value: 0.50 · running\n1/8-cell progress · Space pause/resume · Ctrl+C exit',
  }}
>
  <ol>
    <li>
      <code>initState</code> creates an <code>AnimationController</code>,
      listens for ticker changes, and begins its forward run.
    </li>
    <li>
      Status changes reverse at either endpoint, while each tick calls{' '}
      <code>setState</code> only while the state remains mounted.
    </li>
    <li>
      The fractional controller value becomes the <code>ProgressBar</code> value
      and interpolates its terminal color.
    </li>
    <li>
      Space stops or resumes from the current direction; <code>dispose</code>{' '}
      removes the listener and releases the controller.
    </li>
  </ol>
