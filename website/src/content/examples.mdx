# Examples

All 24 examples on this page ship with Noir and use supported package APIs. Six
include asciicast v2 recordings captured through Noir’s headless driver. Those
recordings exercise the same layout, paint, and parsed-input paths as the test
suite, but they do not prove real-terminal or raw-mode behavior.

## Featured examples

  <ol>
    <li>
      A focused <code>Focus</code> handles Up, Down, +, -, Enter, and Space; the{' '}

      </a>{' '}

      <code>count.value</code> from its Button callback. The{' '}
      <a href="/docs/hooks">Hooks guide</a> explains that opt-in lifecycle.
    </li>
  </ol>
</ExampleSection>

      'NOIR · LIKE REACTOR\n\n       ♥  ✦  ♡  ♥\n\n          █████\n        █████████\n          █████\n\nSpace/Enter/click burst · Ctrl+C exit',

  <ol>

      activation; disposal clears owned simulation state and listeners.
    </li>
  </ol>
