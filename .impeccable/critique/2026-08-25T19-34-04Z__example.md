# Noir example catalog critique

Overall score: **24/40 — Acceptable, but under-curated as a catalog.**

The examples are generally authored at the individual-screen level, but the
collection did not yet provide a deliberate learning path or consistent
interaction/accessibility cues. The formal detector returned no findings only
because it scanned zero Dart files; it is not evidence that terminal UI is
clean.

## Priority findings

- P1 — The flat README inventory obscured a useful sequence and the package
  README omitted several shipped examples.
- P1 — Focused panels relied on color alone, and DataTable sorting was
  pointer-only.
- P1 — Focus Form reported a successful save for blank values and offered no
  visible Save action.
- P2 — Pub Search had no deterministic, network-free recording host even
  though its tests already use an injected catalog boundary.
- P2 — Layout's inert “Sections” pane looked navigable, while the parity screen
  was too dense to serve as an introductory example.

## Resolution applied

- Grouped all 24 entrypoints into Start here, Core concepts, Controls and data,
  Complete apps, Motion, and Advanced and reference.
- Added a structural `›` focus marker, keyboard table sorting, validated form
  submission, and a visible keyed Save button.
- Replaced Chat's parent-owned ASCII animation controller with Noir's standard
  local `Spinner` and made pulse motion pauseable.
- Labeled the layout index as static and parity components as reference-only.
- Added deterministic recording recipes for counter, chat, components, Like
  Reactor, pulse, and fake-backed Pub Search.
